# Web Design & Development Service Page

## Goal
Create a dedicated Web Design & Development page that feels like a natural extension of the current ForgeXD site. Use the attached draft for content direction, while refining copy, hierarchy, and layout where needed.

## What will be built
- Add a dedicated `/services/web-design-development` page.
- Keep the existing Ember & Steel palette, typography, sharp geometry, restrained borders, and editorial spacing.
- Create a strong service introduction focused on business outcomes, supported by relevant website imagery rather than copying the draft composition.
- Include the draft’s core content themes:
  - strategy-led web design and development
  - business goals and user needs
  - website types ForgeXD can build
  - starting investment from R10,000
  - performance, search visibility, conversion, and brand alignment
  - suitable technology selection
  - Discover, Design, Build, Launch process
  - direct enquiry call to action
- Use the ForgeXD signature pattern intentionally as a framing, transition, or focal detail—not as repetitive decoration.
- Link the Web Design & Development service on the main page to the new page and ensure navigation works in both directions.
- Refine wording where needed for clarity, credibility, and consistency with the current brand voice.

## Quality checks
- Review desktop and mobile layouts for balanced spacing, legible text, and no overlap.
- Confirm the page builds cleanly and all navigation and enquiry links work.
- Add complete page-specific title, description, and social sharing metadata.

## Technical details
- Implement the page as a new TanStack route and reuse the existing semantic design tokens.
- Use responsive layout constraints instead of fixed page heights.
- Use an existing relevant asset or create a cohesive supporting image only if it materially improves the service presentation.
